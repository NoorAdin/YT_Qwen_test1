🎬 YouTube PWA

An ad-free Progressive Web App wrapper for m.youtube.com with Picture-in-Picture support.

✨ Features:
  • Direct connection to m.youtube.com (real YouTube content)
  • Picture-in-Picture (PiP) support for multitasking
  • PWA installable on mobile and desktop
  • Standalone app experience
  • Dark theme optimized for video watching

📱 How to Install

  1. Serve this app: Run npx serve . or use any HTTPS server
  2. Open in browser: Navigate to the served URL
  3. Install PWA:
    • Chrome/Edge: Click the install icon in address bar
    • iOS Safari: Tap Share → Add to Home Screen
    • Android Chrome: Tap menu → Install app
  4. Use PiP: Play a video, then tap the red PiP button in bottom-right corner
🎮 Keyboard Shortcuts:
  • Alt + P - Toggle Picture-in-Picture mode

⚠️ Important Notes

HTTPS Required: PWAs require HTTPS (except localhost). Use a secure server for production.

Browser Support: PiP works best in Chrome, Edge, and Safari. Some browsers may have limitations with cross-origin iframes.

Ad Blocking: This app uses m.youtube.com which has fewer ads than desktop. For complete ad-free experience, consider using browser extensions or YouTube Premium.
